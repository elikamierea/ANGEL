# Theme settings

Theme is used to adjust the overall visual style of the GUI. You can start by choosing a preset, then continue fine-tuning as needed.

## What can be adjusted

### 1. Base interface colors

This includes the common colors used across the main interface, such as:

- Background color
- Main text color
- Topbar / Toolbar colors
- Border colors
- Sidebar / Right Panel colors
- Colors for inputs, buttons, menus, dialogs, and other UI elements

These settings define the basic visual style of the entire editor.

### 2. Graph-related colors

You can adjust several key colors inside the graph editing area, such as:

- Edge colors
- Selected edge color
- Node text color
- Node selection colors
- Colors for handles, drag preview, and selection preview

These settings affect readability and interaction feedback on the canvas.

### 3. Agent Chat, Help, and other detailed module colors

In addition to the main interface and the Graph, you can also adjust more local styles, such as:

- Colors for the Agent Chat title bar, buttons, and input fields
- Background and border colors for different message bubbles
- Preview area colors
- Dialog description text colors
- Hyperlink colors in Help

This part mainly affects whether smaller modules feel visually consistent with the rest of the UI.

## What can be adjusted besides color

### 1. Preset

Theme supports choosing a preset as a starting point.

This is useful for:

- Quickly switching the overall style
- Choosing a nearby theme first, then modifying local details
- Switching between different projects or personal preferences

### 2. Node Palette

You can adjust the node color palette.

This affects:

- Node fill color groups
- Node border color groups
- The overall color layering of nodes inside the graph

If you want node colors to feel softer, stronger, or better matched to the current theme, this is a good place to start.

### 3. Grid / Node Base Opacity

You can adjust several transparency-related display parameters, such as:

- Grid opacity
- Base node opacity

These affect how strong the canvas background feels and how visually heavy the nodes appear overall.

### 4. Background image

Theme also supports background-image-related settings, including:

- Whether background images are enabled
- Choosing a background image file
- Clearing the background image
- Adjusting background image opacity

This is useful if you want to add some personal visual style without interfering too much with the main workflow.

## Recommended way to use it

A practical workflow is usually:

1. Choose the closest preset first
2. Then adjust the base interface colors
3. Fine-tune Graph / Agent Chat / Help and other local colors if needed
4. Only at the end decide whether to use a background image and transparency fine-tuning

This is usually much easier than building an entire color system from scratch, and it is much less likely to make the overall style drift into something messy.
