# Create Font

> このページでは、フォントファイルからビットマップフォントリソースを作成する方法を説明します。

## Create Font の用途

`Create Font` は、フォントファイルをプロジェクトで使えるビットマップフォントリソースに変換するために使います。

次のような状況に向いています：

- フォントをプロジェクトリソースにパッケージしたい
- サイズ、charset、hinting、antialias の設定を明示的に制御する必要がある
- 最終的なフォントリソースを生成する前に結果をプレビューしたい

## 基本的なワークフロー

### 1. Create Font を開く

上部メニューから進みます：

- **Resource → Create Font**

開くと、フォントファイルの選択、出力パス、名前、サイズ、charset、プレビュー、エクスポートに関する設定が表示されます。

## 2. フォントファイルを選ぶ

まず入力としてフォントファイルを選びます。

現在サポートされている入力タイプは：

- `.ttf`
- `.otf`
- `.woff`
- `.woff2`

### Windows のシステムフォントに関する現状の注意

**Windows** でシステムフォントを使いたい場合、インストール済みのシステムフォントが GUI からすでに直接使える、と考えないでください。

**現在、システムにインストールされたフォントを自動的に呼び出す完全なサポートはありません。**

現在の実用的な回避方法は：

1. 開く：`C:\Windows\Fonts`
2. 使いたいフォントを見つける
3. そのフォントファイルを、アクセスしやすい別の場所にコピーする
4. `Create Font` でそのコピーしたフォントファイルを選ぶ

つまり、現状でより安全な理解は：

- Windows のシステムフォントは使える
- **ただし選ぶ前に、フォントファイルを `C:\Windows\Fonts` からコピーしておくべき**

これが現段階での暫定的なワークフローです。

## 3. 出力パスと名前を設定する

次に入力します：

- **Path**：出力ディレクトリ
- **Name**：リソース名

デフォルトのパスは通常、次の場所になります：

- `src/assets/fonts`

これはフォントリソースにとって最も自然な場所でもあります。

## 4. サイズ、hinting、antialias を設定する

Create Font は次の設定に対応しています：

- **Size**：フォントサイズ
- **Hinting**：hinting の強さ
- **Antialias**：アンチエイリアスを有効にするか

### Size

フォントサイズは、最終的に生成されるフォントアトラスのグリフサイズに直接影響します。

### Hinting

現在の選択肢は：

- `none`
- `slight`
- `normal`
- `full`

単純な実用的理解は：

- hinting が強いほど、小さいサイズの表示に対して幾何学的な補正をより多く適用する傾向がある
- ただし実際の結果は、フォント自体と求める視覚スタイルにも依存する

### Antialias

現在の選択肢は：

- `on`
- `off`

単純な実用的読み方は通常：

- `on`：より滑らか、一般的な UI や通常のフォント描画に向く
- `off`：よりシャープ、一部のピクセル風のケースや、エッジをぼかしたくない状況に向く

## 5. charset を設定する

この手順は重要です。

`Charset` は、**エクスポートされるフォントリソースに実際にどの文字が含まれるか**を決めます。

つまり、ある文字が charset に含まれていなければ、生成リソースには通常その文字は存在しません。

次のことができます：

- テキストボックスに文字を直接入力する
- または `.txt` ファイルをインポートし、その中の文字をシステムにスキャン・追加させる

これは中国語テキスト、記号セット、プロジェクト固有の UI 文言で特に重要です。

実用的なやり方は：

- よく使うテキストを含む `.txt` ファイルを用意する
- インポートして文字を自動スキャンさせる
- 必要なら特殊記号をいくつか手動で追加する

## 6. フォント結果をプレビューする

Create Font はプレビュー用テキスト入力とプレビューズーム設定を提供します。

次のことができます：

- テスト用テキストを入力する
- プレビューズームを調整する
- 現在のサイズ、hinting、antialias 設定でのおおまかな表示結果を観察する

この手順は次の確認に役立ちます：

- フォントサイズが適切か
- エッジのスタイルが期待どおりか
- 中国語、英語、数字、記号の混在が許容できるか

## 7. Create をクリックしてフォントリソースを生成する

設定が問題なければクリックします：

- **Create**

システムは現在のフォントファイル、サイズ、charset、描画パラメータに基づいてフォントリソースを生成します。

## 生成結果は何か

生成されるフォントリソースは現在、単一のファイルではなく、一連の付随ファイルです。

少なくとも次のように理解できます：

- 1 つ以上のフォントページ画像ファイル
  - 例えば：`_fontpageN.png`
- 1 つのフォントメタデータファイル
  - 例えば：`.font.txt`

つまり、画像ページとメタデータ記述ファイルは一緒に属します。

## 使用上の注意

sprite リソースと同様に、フォントリソースも 1 ファイルずつ移動すべきではありません。

より安全なやり方は：

- 同じフォントリソースのすべてのファイルを一緒に保つ
- 一緒に移動する
- 一緒にコピーする

そうしないと、次のような状態になりかねません：

- メタデータのない画像ページ
- 画像ページのないメタデータ
- 不完全なリソース参照によるフォント読み込みの失敗

## 実用的な提案

初めて Create Font を使う場合、推奨される順序は通常：

1. アクセスしやすいフォントファイルを 1 つから始める
2. まず小さめの charset でテストする
3. プレビューを確認しながらサイズ、hinting、antialias を調整する
4. まず最小限の使えるバージョンを生成する
5. フローが確認できてから、より完全な charset に拡張する

これは、最初から巨大な charset をエクスポートするよりも、はるかにトラブルシューティングしやすいです。
