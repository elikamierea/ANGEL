# Create Sprite

> このページでは、画像フレームから Sprite リソースを作成する方法を説明します。

## Create Sprite の用途

`Create Sprite` は、1 枚または複数の画像を、プロジェクト内で使える sprite リソースに整理するために使います。

次のような状況に向いています：

- すでに静止画があり、それを sprite として使いたい
- 連続した複数のフレーム画像があり、それらをアニメーションにまとめたい
- pivot を明示的に設定し、リソースのメタデータに書き込みたい

## 基本的なワークフロー

### 1. Create Sprite を開く

上部メニューから進みます：

- **Resource → Create Sprite**

開くと、画像のインポート、出力パスの設定、リソースの命名、pivot の調整、フレームのプレビューのための UI が表示されます。

### 2. 入力画像を選ぶ

ファイル選択エリアで 1 枚または複数の画像をインポートします。

- 1 枚だけ選んだ場合は、単一フレームの sprite として理解できます
- 複数選んだ場合は、現在のインポート順で複数のフレームとして生成されます

簡単なフレームアニメーションを作りたい場合は、通常ここで連続フレーム画像を一度にすべてインポートします。

### 3. 出力パスと名前を設定する

次に入力します：

- **Path**：出力ディレクトリ
- **Name**：リソース名

デフォルトのパスは通常、次の場所になります：

- `src/assets/sprites`

これは sprite リソースにとって最も自然な場所でもあります。

## 4. Pivot を調整する

Create Sprite は次の設定に対応しています：

- `Pivot X`
- `Pivot Y`

pivot は生成されるリソースのメタデータに書き込まれ、その sprite の基準点を表します。

実用的な理解の仕方は：

- キャラクターの足元の点
- オブジェクトの中心点
- 武器の握り付近の位置
- UI タイルの整列の基準点

次のことができます：

- 値を直接入力する
- プレビューを見ながら微調整する

## 5. フレームをプレビューする

プレビューエリアでは：

- 現在のフレームを表示
- 前または次のフレームに切り替え
- pivot の位置が適切か確認

複数の画像をインポートした場合、この手順は特に重要です。次のことを確認できるからです：

- フレーム順が正しいか
- 各フレームの内容が正常か
- 現在の pivot がフレーム全体に適しているか

## 6. Create をクリックしてリソースを生成する

すべて問題なければクリックします：

- **Create**

システムは現在の入力画像、名前、パス、pivot に基づいて、対応する sprite リソースファイルを生成します。

## 生成結果は何か

ここに重要な点があります：

**生成される sprite は 1 つのファイルではなく、2 つのファイルの組み合わせです。**

通常は次のように理解できます：

1. **画像ファイル**
   - 実際の sprite 画像内容（atlas / 合成後の画像）を保存

2. **メタデータファイル**
   - その sprite の説明情報を保存
   - 例えば：
     - 画像サイズ
     - フレーム数
     - フレームごとの情報
     - pivot 位置

現在の実装では、このメタデータは**別の付随ファイル**として書き出されます。

## 非常に重要な注意

後でこの sprite リソースを移動、コピー、整理する場合：

- **画像ファイルとメタデータファイルは一緒に移動する必要があります**
- どちらか一方だけを移動しない

そうしないと、よくある結果は：

- 画像は残っているが、プロジェクトが frame / pivot などの情報を把握できない
- メタデータは残っているが、実際の画像が見つからない
- リソース参照が壊れる、または読み込みに失敗する

そのため、最も安全な理解の仕方は：

**この 2 つのファイルが一緒で 1 つの完全な sprite リソースを構成します。**

## どんなときに役立つか

Create Sprite は次に向いています：

- キャラクターのフレームアニメーションを素早くインポート
- 単純なオブジェクト sprite を生成
- すぐ使える画像リソースをプロジェクトに追加
- メタデータを手書きせずに sprite リソースを作成

## 実用的な提案

初めて Create Sprite を使う場合、推奨される順序は通常：

1. まず 1 枚、または数枚の画像でテストする
2. パス、名前、pivot が期待どおりか確認する
3. 生成後、2 つの出力ファイルがそろっているか確認する
4. その後で、より本格的・大規模なリソース作成に進む

こうすることでまずワークフローを動かせ、後で大量のフレームを一度にインポートする際のデバッグの難しさを避けられます。
