# プロジェクトの作成と開く（Project I/O）

## New Project

新しいプロジェクトを作成するときは、開始テンプレートを選びます。テンプレートは、どれだけの**規模**（構造と agent）を用意するかで異なります。

### Default

`Default` は最小の出発点で、2 レイヤー構成にコーディング agent が 1 つだけです。次のようなワークフローに向いています：

- すでに基本設計がある
- 多くの前準備となる構造を先に作りたくない
- すぐにゲーム層のコードを書き始めたい
- まず最小の実行可能なループを動かすことを重視する

言い換えると、`Default` は「**設計があり、そのまま直接コードに入る**」というワークフローに向いています。

初めてローカル環境を確認する場合にも適しています。経路が短く、オーバーヘッドが少ないからです。

### Extended

`Extended` はより大きな出発点で、4 レイヤー構成に設計・オーケストレーション・コーディングの agent を備えます。次のようなワークフローに向いています：

- すでに初期設計がある
- その設計をさらに洗練させたい
- まずコード構造と実装手順を計画したい
- そのうえで徐々に実際のコーディングに入りたい

言い換えると、`Extended` は「**まず設計と構造を整理し、それから実装に入る**」というワークフローに向いています。

## プロジェクトフォルダのおおまかな構成

新しいプロジェクトを作成すると、基本的にはプロジェクトディレクトリが生成されます。その構造はおおまかに次のように理解できます：

### 1. グラフ関連の情報

グラフエディタのノード、エッジ、レイヤー、UI 状態などのプロジェクトデータは、プロジェクト設定ファイルに保存されます。

現在のプロジェクト形式は「**プロジェクトディレクトリ + プロジェクト設定ファイル**」として構成されており、プロジェクトを開くときも直接プロジェクトディレクトリを選び、その中のプロジェクト設定を GUI に識別させます。

この部分は次のように理解できます：

- グラフ構造データ
- エディタ状態データ
- 現在のプロジェクトに関連する GUI 保存情報

### 2. コード関連の構造

コードプロジェクト本体は標準的な工程ディレクトリに置かれます。中心的な部分は通常：

- `src/game/`：ゲーム層コード、実際の実装の主な領域
- `src/engine/`：下位のエンジン部分
- `src/platform/`：プラットフォーム層
- `vendor/`：サードパーティ依存、またはテンプレートに同梱されるライブラリ
- `tools/`：プロジェクトに付属する補助スクリプトや内蔵ツール

日常的に機能開発を続けるだけなら、最もよく触れるのは通常：

- `src/game/`

### 3. リソースファイルの場所

プロジェクトのリソースは現在、主に次の場所にあります：

- `src/assets/sprites/`
- `src/assets/fonts/`
- `src/assets/audio/`
- `src/assets/other/`

つまり単純に次のように理解できます：

- Sprite リソースは `sprites`
- フォントリソースは `fonts`
- オーディオリソースは `audio`
- その他のリソースは `other`

これが、Create Sprite / Create Font などのリソース関連ツールが最終的にこれらのディレクトリに書き戻す理由でもあります。

### 4. Agent 関連の情報

プロジェクトが agent 側のプロジェクト内メモリ/コンテキストファイルを使う場合、それらは通常 agent ごとに別々のディレクトリに整理されます。

この部分は次のように理解できます：

- 異なる agent それぞれのメモリファイル
- セッション初期化に使うコンテキスト素材

これは通常のゲームコンテンツではなく、下位のエンジンコードでもありません。プロジェクト内で agent が使う補助情報層に近いものです。

## Open / Save / Save As

### Open

- **Open**：既存のプロジェクトを開く
- 現在のワークフローは、ばらばらの 1 ファイルを選ぶのではなく、プロジェクトディレクトリを直接選ぶ

### Save

- **Save**：現在のプロジェクト状態を保存
- これには通常、グラフエディタのプロジェクトデータと、現在のプロジェクトに紐づく保存内容が含まれる

### Save As

- **Save As**：現在のプロジェクトを別の場所に保存

## 実用的な理解の仕方

New Project / Open / Save を手早く理解したいだけなら、まず次のように覚えるとよいでしょう：

- `Default`：「**設計があり、すぐにコードを始める**」に向く
- `Extended`：「**まず設計/洗練/計画し、それから実装**」に向く
- グラフデータはプロジェクト設定に保存される
- コードは主に `src/` にある
- リソースは主に `src/assets/` にある
- Agent 関連のコンテキストはプロジェクトと一緒に整理されるが、別の情報層に属する
