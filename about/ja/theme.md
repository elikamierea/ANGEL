# Theme 設定

Theme は GUI 全体の視覚スタイルを調整するために使います。まず preset を選び、必要に応じて微調整を続けられます。

## 何を調整できるか

### 1. 基本インターフェースの色

メインインターフェース全体で共通して使われる色が含まれます。例えば：

- 背景色
- メインテキスト色
- Topbar / Toolbar の色
- ボーダー色
- Sidebar / Right Panel の色
- 入力欄、ボタン、メニュー、ダイアログなどの UI 要素の色

これらの設定はエディタ全体の基本的な視覚スタイルを決めます。

### 2. Graph 関連の色

グラフ編集エリア内のいくつかの重要な色を調整できます。例えば：

- エッジの色
- 選択中のエッジの色
- ノードのテキスト色
- ノードの選択状態の色
- handle / drag preview / selection preview の色

これらの設定はキャンバス上の可読性と操作フィードバックに影響します。

### 3. Agent Chat、Help などの細部の色

メインインターフェースと Graph 以外にも、より局所的なスタイルを調整できます。例えば：

- Agent Chat のタイトルバー、ボタン、入力欄の色
- 異なるメッセージバブルの背景 / ボーダー色
- プレビューエリアの色
- ダイアログ説明文の色
- Help 内のハイパーリンクの色

この部分は主に、細かいモジュールが全体と視覚的に統一されているかに影響します。

## 色以外に調整できること

### 1. Preset

Theme は出発点として preset を選ぶことができます。

これが役立つ場面：

- 全体スタイルを素早く切り替える
- 近いテーマをまず選び、その後局所的に修正する
- 異なるプロジェクトや個人の好みの間で切り替える

### 2. Node Palette

ノードのカラーパレット（palette）を調整できます。

これが影響するもの：

- ノードの塗りつぶし色グループ
- ノードのボーダー色グループ
- グラフ内のノード全体の配色レイヤー

ノードの色をより柔らかく、より鮮やかに、または現在のテーマにより合うようにしたい場合、ここから始めるとよいでしょう。

### 3. Grid / Node Base Opacity

表示の透明度に関するいくつかのパラメータを調整できます。例えば：

- Grid の不透明度
- ノードの基本不透明度

これらはキャンバス背景の存在感や、ノード全体の視覚的な重さに影響します。

### 4. 背景画像

Theme は背景画像関連の設定にも対応しています。含まれるもの：

- 背景画像を有効にするかどうか
- 背景画像ファイルの選択
- 背景画像のクリア
- 背景画像の不透明度の調整

メインのワークフローをあまり妨げずに、個人的な視覚スタイルを加えたい場合に便利です。

## おすすめの使い方

実用的なワークフローは通常：

1. まず最も近い preset を選ぶ
2. 次に基本インターフェースの色を調整する
3. 必要に応じて Graph / Agent Chat / Help などの局所的な色を微調整する
4. 最後に背景画像と透明度の微調整を使うかどうかを決める

これは、色のシステム全体を一から作るよりもずっと簡単で、全体スタイルが乱雑になりにくくなります。
