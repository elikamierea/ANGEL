# Create Font

> 이 페이지에서는 폰트 파일에서 비트맵 폰트 리소스를 만드는 방법을 설명합니다.

## Create Font 의 용도

`Create Font` 는 폰트 파일을 프로젝트에서 사용할 수 있는 비트맵 폰트 리소스로 변환하는 데 사용됩니다.

다음과 같은 상황에 적합합니다：

- 폰트를 프로젝트 리소스로 패키징하고 싶음
- 크기, charset, hinting, antialias 설정을 명확히 제어해야 함
- 최종 폰트 리소스를 생성하기 전에 결과를 미리 보고 싶음

## 기본 작업 흐름

### 1. Create Font 열기

상단 메뉴에서 들어갑니다：

- **Resource → Create Font**

열면 폰트 파일 선택, 출력 경로, 이름, 크기, charset, 미리보기, 내보내기와 관련된 설정이 보입니다.

## 2. 폰트 파일 선택

먼저 입력으로 폰트 파일을 선택합니다.

현재 지원되는 입력 유형은：

- `.ttf`
- `.otf`
- `.woff`
- `.woff2`

### Windows 의 시스템 폰트에 관한 현재 주의 사항

**Windows** 에서 시스템 폰트를 사용하고 싶다면, 설치된 시스템 폰트가 GUI 에서 이미 바로 사용 가능하다고 여기지 마세요.

**현재 시스템에 설치된 폰트를 자동으로 호출하는 완전한 지원은 없습니다.**

현재 실용적인 우회 방법은：

1. 열기：`C:\Windows\Fonts`
2. 사용하려는 폰트 찾기
3. 그 폰트 파일을 접근하기 쉬운 다른 위치로 복사
4. `Create Font` 에서 그 복사한 폰트 파일을 선택

즉, 현재로서 더 안전한 이해는：

- Windows 시스템 폰트를 사용할 수 있음
- **단, 선택하기 전에 폰트 파일을 `C:\Windows\Fonts` 에서 복사해 두어야 함**

이것이 현 단계의 임시 작업 방식입니다.

## 3. 출력 경로와 이름 설정

다음으로 입력합니다：

- **Path**：출력 디렉터리
- **Name**：리소스 이름

기본 경로는 보통 다음 위치가 됩니다：

- `src/assets/fonts`

이는 폰트 리소스에 가장 자연스러운 위치이기도 합니다.

## 4. 크기, Hinting, Antialias 설정

Create Font 는 다음 설정을 지원합니다：

- **Size**：폰트 크기
- **Hinting**：hinting 강도
- **Antialias**：안티앨리어싱 활성화 여부

### Size

폰트 크기는 최종 생성되는 폰트 아틀라스의 글리프 크기에 직접 영향을 줍니다.

### Hinting

현재 선택지는：

- `none`
- `slight`
- `normal`
- `full`

단순한 실용적 이해는：

- hinting 이 강할수록 작은 크기 표시에 대해 기하학적 보정을 더 많이 적용하는 경향이 있음
- 다만 실제 결과는 폰트 자체와 원하는 시각 스타일에도 달려 있음

### Antialias

현재 선택지는：

- `on`
- `off`

단순한 실용적 해석은 보통：

- `on`：더 매끄러움, 일반 UI / 일반 폰트 렌더링에 적합
- `off`：더 또렷함, 일부 픽셀 스타일이나 가장자리를 부드럽게 하고 싶지 않은 상황에 적합

## 5. Charset（문자 집합）설정

이 단계는 중요합니다.

`Charset` 은 **내보내는 폰트 리소스에 실제로 어떤 문자가 포함되는지** 를 결정합니다.

즉, 어떤 문자가 charset 에 들어가지 않으면, 보통 생성 리소스에는 그 문자가 존재하지 않습니다.

다음을 할 수 있습니다：

- 텍스트 상자에 문자를 직접 입력
- 또는 `.txt` 파일을 가져와, 그 안에 나오는 문자를 시스템이 스캔해 추가하도록 함

이는 중국어 텍스트, 기호 집합, 프로젝트 고유 UI 문구에 특히 중요합니다.

실용적인 방법은：

- 자주 쓰는 텍스트가 담긴 `.txt` 파일을 준비
- 가져와서 문자를 자동 스캔하게 함
- 필요하면 특수 기호 몇 개를 수동으로 추가

## 6. 폰트 결과 미리보기

Create Font 는 미리보기 텍스트 입력과 미리보기 확대 설정을 제공합니다.

다음을 할 수 있습니다：

- 테스트 텍스트 입력
- 미리보기 확대 조정
- 현재 크기, hinting, antialias 설정에서의 대략적인 표시 결과 관찰

이 단계는 다음 확인에 좋습니다：

- 폰트 크기가 적절한지
- 가장자리 스타일이 예상과 맞는지
- 중국어, 영어, 숫자, 기호 혼용이 허용 가능한지

## 7. Create 를 클릭해 폰트 리소스 생성

설정이 문제없으면 클릭합니다：

- **Create**

시스템은 현재 폰트 파일, 크기, charset, 렌더링 매개변수를 바탕으로 폰트 리소스를 생성합니다.

## 생성 결과는 무엇인가

생성되는 폰트 리소스는 현재 단일 파일이 아니라 일련의 동반 파일입니다.

최소한 다음과 같이 이해할 수 있습니다：

- 하나 이상의 폰트 페이지 이미지 파일
  - 예：`_fontpageN.png`
- 하나의 폰트 메타데이터 파일
  - 예：`.font.txt`

즉, 이미지 페이지와 메타데이터 설명 파일은 함께 속합니다.

## 사용 시 주의 사항

sprite 리소스와 마찬가지로, 폰트 리소스도 파일을 하나씩 따로 이동해서는 안 됩니다.

더 안전한 방법은：

- 같은 폰트 리소스의 모든 파일을 함께 유지
- 함께 이동
- 함께 복사

그렇지 않으면 다음 상태가 될 수 있습니다：

- 메타데이터 없는 이미지 페이지
- 이미지 페이지 없는 메타데이터
- 불완전한 리소스 참조로 인한 폰트 로드 실패

## 실용적인 제안

Create Font 를 처음 사용한다면, 권장되는 순서는 보통：

1. 접근하기 쉬운 폰트 파일 하나로 시작
2. 먼저 작은 charset 으로 테스트
3. 미리보기를 확인하며 크기, hinting, antialias 조정
4. 먼저 최소한의 사용 가능한 버전을 생성
5. 흐름이 확인되면 더 완전한 charset 으로 확장

이는 처음부터 매우 큰 charset 을 내보내는 것보다 보통 훨씬 문제 해결이 쉽습니다.
