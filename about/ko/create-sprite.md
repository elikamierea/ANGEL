# Create Sprite

> 이 페이지에서는 이미지 프레임에서 Sprite 리소스를 만드는 방법을 설명합니다.

## Create Sprite 의 용도

`Create Sprite` 는 한 장 또는 여러 장의 이미지를 프로젝트에서 사용할 수 있는 sprite 리소스로 정리하는 데 사용됩니다.

다음과 같은 상황에 적합합니다：

- 이미 정지 이미지가 있고, 그것을 sprite 로 사용하고 싶음
- 연속된 여러 프레임 이미지가 있고, 그것들을 애니메이션으로 합치고 싶음
- pivot 을 명확히 설정하고, 리소스 메타데이터에 함께 기록하고 싶음

## 기본 작업 흐름

### 1. Create Sprite 열기

상단 메뉴에서 들어갑니다：

- **Resource → Create Sprite**

열면 이미지 가져오기, 출력 경로 설정, 리소스 이름 지정, pivot 조정, 프레임 미리보기를 위한 UI 가 보입니다.

### 2. 입력 이미지 선택

파일 선택 영역에서 한 장 또는 여러 장의 이미지를 가져옵니다.

- 한 장만 선택하면 단일 프레임 sprite 로 이해할 수 있습니다
- 여러 장을 선택하면 현재 가져오기 순서대로 여러 프레임으로 생성됩니다

간단한 프레임 애니메이션을 만들려면, 보통 여기서 연속 프레임 이미지를 한 번에 모두 가져옵니다.

### 3. 출력 경로와 이름 설정

다음으로 입력합니다：

- **Path**：출력 디렉터리
- **Name**：리소스 이름

기본 경로는 보통 다음 위치가 됩니다：

- `src/assets/sprites`

이는 sprite 리소스에 가장 자연스러운 위치이기도 합니다.

## 4. Pivot 조정

Create Sprite 는 다음 설정을 지원합니다：

- `Pivot X`
- `Pivot Y`

pivot 은 생성되는 리소스의 메타데이터에 기록되어, 그 sprite 의 기준점을 나타냅니다.

실용적인 이해 방식은：

- 캐릭터 발밑 점
- 오브젝트 중심점
- 무기 손잡이 부근 위치
- UI 타일의 정렬 기준점

다음을 할 수 있습니다：

- 값을 직접 입력
- 미리보기를 보며 미세 조정

## 5. Frame 미리보기

미리보기 영역에서：

- 현재 프레임 확인
- 이전 / 다음 프레임으로 전환
- pivot 위치가 적절한지 관찰

여러 이미지를 가져왔다면 이 단계는 특히 중요합니다. 다음을 확인하는 데 도움이 되기 때문입니다：

- 프레임 순서가 예상과 맞는지
- 각 프레임 내용이 정상인지
- 현재 pivot 이 프레임 전체에 적합한지

## 6. Create 를 클릭해 리소스 생성

문제가 없으면 클릭합니다：

- **Create**

시스템은 현재 입력 이미지, 이름, 경로, pivot 을 바탕으로 해당 sprite 리소스 파일을 생성합니다.

## 생성 결과는 무엇인가

여기에 매우 중요한 점이 있습니다：

**생성되는 sprite 는 단일 파일이 아니라 두 개의 파일입니다.**

보통 다음과 같이 이해할 수 있습니다：

1. **이미지 파일**
   - 실제 sprite 이미지 내용（atlas / 합성된 이미지）을 저장

2. **메타데이터 파일**
   - 그 sprite 의 설명 정보를 저장
   - 예：
     - 이미지 크기
     - 프레임 수
     - 프레임별 정보
     - pivot 위치

현재 구현에서는 이 메타데이터가 **별도의 동반 파일**로 함께 기록됩니다.

## 매우 중요한 주의 사항

나중에 이 sprite 리소스를 이동, 복사, 정리할 때：

- **이미지 파일과 메타데이터 파일은 반드시 함께 이동해야 합니다**
- 둘 중 하나만 이동하지 마세요

그렇지 않으면 흔한 결과는：

- 이미지만 남고, 프로젝트가 frame / pivot 등 정보를 알지 못함
- 메타데이터만 남고, 실제 이미지를 찾지 못함
- 리소스 참조가 깨지거나 로드에 실패함

따라서 가장 안전한 이해 방식은：

**이 두 파일이 함께 하나의 완전한 sprite 리소스를 구성합니다.**

## 언제 가장 유용한가

Create Sprite 는 다음에 적합합니다：

- 캐릭터 프레임 애니메이션을 빠르게 가져오기
- 단순한 오브젝트 sprite 생성
- 바로 사용할 수 있는 이미지 리소스를 프로젝트에 추가
- 메타데이터를 직접 작성하지 않고 sprite 리소스 생성

## 실용적인 제안

Create Sprite 를 처음 사용한다면, 권장되는 순서는 보통：

1. 먼저 한 장 또는 몇 장의 이미지로 테스트
2. 경로, 이름, pivot 이 예상과 맞는지 확인
3. 생성 후 두 출력 파일이 모두 있는지 확인
4. 그다음에 더 본격적이고 대규모인 리소스 작성으로 진행

이렇게 하면 먼저 작업 흐름을 작동시킬 수 있고, 나중에 많은 프레임을 한 번에 가져올 때의 디버깅 어려움을 피할 수 있습니다.
