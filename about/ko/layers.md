# Layer 시스템

Layer 는 정보 전개 수준을 표현하는 데 사용됩니다.

이는 단순한 「표시 켜기/끄기」가 아니라, 같은 그래프 구조 위에서 다음을 제어하는 방식에 가깝습니다：

- 지금 얼마나 많은 디테일을 보고 있는지
- 지금 어느 수준의 정보를 편집하고 있는지
- 어떤 설계 내용을 어느 추상 수준에 두어야 하는지

## Layer 가 대략 어떻게 작동하는가

흔히 이해하는 방식은：

- 낮은 층일수록 더 개괄적이고 골격적인 정보
- 높은 층일수록 더 전개되고 구체적인 내용

실제 사용에서 현재 활성 층은 보통 다음에 영향을 줍니다：

- 표시 범위
- 편집 가능 범위
- 일부 노드에 현재 표시되는 detail 수준

## 모든 프로젝트가 반드시 같은 층 수를 쓰는 것은 아니다

여기서 특히 강조하고 싶은 점이 있습니다：

**모든 프로젝트가 반드시 완전히 같은 Layer 복잡도로 사용해야 하는 것은 아닙니다.**

대략 다음과 같이 이해할 수 있습니다：

### 1. 4 층 모드

일부 프로젝트는 더 완전한 4 층 구조를 사용합니다. 일반적으로：

- `L0`
- `L1`
- `L2`
- `L3`

이 모드가 적합한 경우：

- 그래프 구조가 더 복잡함
- 설계 전개 단계가 더 많음
- 정보를 더 세밀하게 나누고 싶음

### 2. 단순화 모드

다른 프로젝트는 Layer 를 2 층 정도로 단순화하여 이해하고 사용하기도 합니다.

이 모드가 적합한 경우：

- 프로젝트 자체 규모가 작음
- 설계를 너무 세밀하게 나눌 필요가 없음
- 많은 추상을 유지하기보다 빠르게 직접 구현에 들어가고 싶음

따라서 실제 프로젝트에서 Layer 의 「존재」는 일관되지만, 「얼마나 세밀하게 쓰는가」는 다를 수 있습니다.

## 사용 권장 사항

Layer 를 처음 사용한다면, 가장 실용적인 이해 방식은 보통：

- 먼저 「정보 전개 수준」으로 받아들이기
- 처음부터 각 층을 너무 이론적으로 정의하려 하지 않기
- 프로젝트 복잡도에 따라 4 층으로 세분할지, 더 단순한 방식으로 쓸지 결정하기

프로젝트가 크고 설계 관계가 많으면 4 층이 큰 도움이 됩니다. 프로젝트 목표가 더 직접적이고 진행이 빠르면 단순한 사용 방식도 대개 충분히 괜찮습니다.
