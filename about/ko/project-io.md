# 프로젝트 생성과 열기（Project I/O）

## New Project

새 프로젝트를 만들 때는 시작 템플릿을 선택합니다. 템플릿은 얼마나 많은 **규모**（구조와 agent）를 구성하는지에 따라 다릅니다.

### Default

`Default` 은 가장 작은 출발점으로, 2개 레이어 구성에 코딩 agent 하나만 둡니다. 다음과 같은 워크플로에 적합합니다：

- 이미 기본 설계가 있음
- 많은 사전 구조를 먼저 깔고 싶지 않음
- 바로 게임 계층 코드를 쓰기 시작하고 싶음
- 먼저 최소 실행 가능한 루프를 만드는 것을 더 중시함

다시 말해 `Default` 은 「**설계가 있고, 그대로 바로 코드에 들어가는**」 작업 방식에 더 적합합니다.

처음 로컬 환경을 확인할 때에도 적합합니다. 경로가 더 짧고 부담이 적기 때문입니다.

### Extended

`Extended` 은 더 큰 출발점으로, 4개 레이어 구조에 설계·오케스트레이션·코딩 agent 를 갖춥니다. 다음과 같은 워크플로에 적합합니다：

- 이미 초기 설계가 있음
- 그 설계를 계속 다듬고 싶음
- 먼저 코드 구조와 구현 단계를 계획하고 싶음
- 그런 다음 점차 실제 코딩에 들어가고 싶음

다시 말해 `Extended` 은 「**먼저 설계와 구조를 정리한 뒤 구현에 들어가는**」 작업 방식에 더 적합합니다.

## 프로젝트 폴더의 대략적인 구성

새 프로젝트를 만들면 본질적으로 프로젝트 디렉터리가 생성됩니다. 그 구조는 대략 다음과 같이 이해할 수 있습니다：

### 1. 그래프 관련 정보

그래프 에디터의 노드, 엣지, 계층, UI 상태 등 프로젝트 데이터는 프로젝트 설정 파일에 저장됩니다.

현재 프로젝트 형식은 「**프로젝트 디렉터리 + 프로젝트 설정 파일**」 로 구성되며, 프로젝트를 열 때도 프로젝트 디렉터리를 직접 선택하면 GUI 가 그 안의 프로젝트 설정을 식별합니다.

이 부분은 다음과 같이 이해할 수 있습니다：

- 그래프 구조 데이터
- 에디터 상태 데이터
- 현재 프로젝트와 관련된 GUI 저장 정보

### 2. 코드 관련 구조

코드 프로젝트 본체는 표준 공정 디렉터리에 놓입니다. 핵심 부분은 보통：

- `src/game/`：게임 계층 코드, 실제 구현의 주요 영역
- `src/engine/`：하위 엔진 부분
- `src/platform/`：플랫폼 계층
- `vendor/`：서드파티 의존성 또는 템플릿과 함께 배포되는 라이브러리
- `tools/`：프로젝트에 동봉된 보조 스크립트나 내장 도구

일상적으로 기능 개발을 이어가는 정도라면, 가장 자주 다루는 것은 보통：

- `src/game/`

### 3. 리소스 파일의 위치

프로젝트 리소스는 현재 주로 다음 위치에 있습니다：

- `src/assets/sprites/`
- `src/assets/fonts/`
- `src/assets/audio/`
- `src/assets/other/`

따라서 단순하게 다음과 같이 이해할 수 있습니다：

- Sprite 리소스는 `sprites`
- 폰트 리소스는 `fonts`
- 오디오 리소스는 `audio`
- 기타 리소스는 `other`

이것이 Create Sprite / Create Font 같은 리소스 관련 도구가 최종적으로 이 디렉터리들로 다시 쓰게 되는 이유이기도 합니다.

### 4. Agent 관련 정보

프로젝트가 agent 측의 프로젝트 내 메모리/컨텍스트 파일을 사용한다면, 그것들은 보통 agent 별로 별도의 디렉터리에 정리됩니다.

이 부분은 다음과 같이 이해할 수 있습니다：

- 서로 다른 agent 각각의 메모리 파일
- 세션 초기화에 쓰이는 컨텍스트 자료

이는 일반 게임 콘텐츠가 아니며, 하위 엔진 코드도 아닙니다. 프로젝트 안에서 agent 가 사용하는 보조 정보 계층에 더 가깝습니다.

## Open / Save / Save As

### Open

- **Open**：기존 프로젝트 열기
- 현재 워크플로는 흩어진 한 파일을 고르는 것이 아니라 프로젝트 디렉터리를 직접 선택하는 것

### Save

- **Save**：현재 프로젝트 상태 저장
- 여기에는 보통 그래프 에디터의 프로젝트 데이터와 현재 프로젝트에 묶인 저장 내용이 포함됨

### Save As

- **Save As**：현재 프로젝트를 다른 위치에 저장

## 실용적인 이해 방식

New Project / Open / Save 를 빠르게 이해하고 싶다면, 먼저 다음과 같이 기억하면 됩니다：

- `Default`：「**설계가 있고 바로 코드 시작**」에 적합
- `Extended`：「**먼저 설계/다듬기/계획한 뒤 구현**」에 적합
- 그래프 데이터는 프로젝트 설정에 저장됨
- 코드는 주로 `src/` 에 있음
- 리소스는 주로 `src/assets/` 에 있음
- Agent 관련 컨텍스트는 프로젝트와 함께 정리되지만 별도의 정보 계층에 속함
