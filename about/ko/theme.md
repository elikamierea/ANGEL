# Theme 설정

Theme 는 GUI 의 전체 시각 스타일을 조정하는 데 사용됩니다. 먼저 preset 을 선택한 뒤, 필요에 따라 계속 미세 조정할 수 있습니다.

## 무엇을 조정할 수 있는가

### 1. 기본 인터페이스 색상

메인 인터페이스 전반에서 공통으로 사용되는 색상이 포함됩니다. 예：

- 배경색
- 기본 텍스트 색
- Topbar / Toolbar 색
- 테두리 색
- Sidebar / Right Panel 색
- 입력란, 버튼, 메뉴, 대화 상자 등 UI 요소의 색

이 설정들은 전체 에디터의 기본 시각 스타일을 결정합니다.

### 2. Graph 관련 색상

그래프 편집 영역 내의 몇 가지 핵심 색상을 조정할 수 있습니다. 예：

- 엣지 색
- 선택된 엣지 색
- 노드 텍스트 색
- 노드 선택 상태 색
- handle / drag preview / selection preview 색

이 설정들은 캔버스의 가독성과 조작 피드백에 영향을 줍니다.

### 3. Agent Chat, Help 등 세부 모듈 색상

메인 인터페이스와 Graph 외에도, 더 국소적인 스타일을 조정할 수 있습니다. 예：

- Agent Chat 제목 표시줄, 버튼, 입력란 색
- 서로 다른 메시지 말풍선의 배경 / 테두리 색
- 미리보기 영역 색
- 대화 상자 설명 문구 색
- Help 의 하이퍼링크 색

이 부분은 주로 작은 모듈이 나머지 UI 와 시각적으로 일관되는지에 영향을 줍니다.

## 색상 외에 조정할 수 있는 것

### 1. Preset

Theme 은 출발점으로 preset 을 선택할 수 있습니다.

유용한 경우：

- 전체 스타일을 빠르게 전환
- 가까운 테마를 먼저 선택한 뒤 국소적으로 수정
- 서로 다른 프로젝트나 개인 취향 사이에서 전환

### 2. Node Palette

노드 색상 팔레트（palette）를 조정할 수 있습니다.

영향을 주는 것：

- 노드 채우기 색 그룹
- 노드 테두리 색 그룹
- 그래프 내 노드의 전체 색상 레이어링

노드 색을 더 부드럽거나 더 선명하게, 또는 현재 테마에 더 어울리게 하고 싶다면 여기서 시작하면 좋습니다.

### 3. Grid / Node Base Opacity

표시 투명도와 관련된 몇 가지 매개변수를 조정할 수 있습니다. 예：

- Grid 불투명도
- 노드 기본 불투명도

이는 캔버스 배경의 존재감과 노드 전체의 시각적 무게감에 영향을 줍니다.

### 4. 배경 이미지

Theme 은 배경 이미지 관련 설정도 지원합니다. 포함되는 것：

- 배경 이미지 활성화 여부
- 배경 이미지 파일 선택
- 배경 이미지 지우기
- 배경 이미지 불투명도 조정

메인 워크플로를 크게 방해하지 않으면서 개인적인 시각 스타일을 더하고 싶을 때 유용합니다.

## 권장 사용 방식

실용적인 워크플로는 보통：

1. 먼저 가장 가까운 preset 을 선택
2. 그다음 기본 인터페이스 색상을 조정
3. 필요에 따라 Graph / Agent Chat / Help 등 국소 색상을 미세 조정
4. 마지막에 배경 이미지와 투명도 미세 조정을 사용할지 결정

이는 색상 체계 전체를 처음부터 만드는 것보다 훨씬 쉽고, 전체 스타일이 지저분해질 가능성도 훨씬 적습니다.
