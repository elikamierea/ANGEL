# Create Font

> 本页说明如何从字体文件创建位图字体资源。

## Create Font 是做什么的

`Create Font` 用来把一个字体文件转换成项目可用的位图字体资源。

它比较适合这些情况：

- 你想把一套字体打包进项目资源
- 你需要明确控制字号、字符集、hinting 和 antialias
- 你希望先预览，再生成最终字体资源

## 基本操作流程

### 1. 打开 Create Font

从顶部菜单进入：

- **Resource → Create Font**

打开后，会看到字体文件选择、输出路径、名称、字号、字符集、预览与导出等相关设置。

## 2. 选择字体文件

先选择一个字体文件作为输入。

当前支持的输入类型包括：

- `.ttf`
- `.otf`
- `.woff`
- `.woff2`

### Windows 系统下关于“系统字体”的一个当前注意事项

如果你想在 **Windows** 下使用系统字体，目前不要直接把“系统已安装字体”当成已经可被 GUI 直接调用。

**我们目前还没有做“直接调用系统字体”的完整支持。**

当前可行的临时绕过方法是：

1. 进入：`C:\Windows\Fonts`
2. 找到你要使用的字体
3. 将字体文件复制到外部某个你方便访问的位置
4. 再在 `Create Font` 中选择这个复制出来的字体文件

也就是说，当前更稳妥的理解是：

- 可以使用 Windows 系统字体
- **但要先把对应字体文件从 `C:\Windows\Fonts` 复制出来再选**

这是目前阶段的临时工作方法。

## 3. 设置输出路径和名称

接下来需要填写：

- **Path**：输出目录
- **Name**：资源名称

默认路径通常会落在：

- `src/assets/fonts`

这也是最自然的字体资源存放位置。

## 4. 设置字号、Hinting 和 Antialias

Create Font 支持设置：

- **Size**：字号
- **Hinting**：字体微调强度
- **Antialias**：是否开启抗锯齿

### Size

字号会直接影响最终生成字体图集的字形大小。

### Hinting

当前可选：

- `none`
- `slight`
- `normal`
- `full`

一般可以把它理解成：

- 越强的 hinting，越偏向对小字号显示进行几何修正
- 但具体观感仍然需要结合字体本身和目标风格去看

### Antialias

当前可选：

- `on`
- `off`

通常可以简单理解为：

- `on`：更平滑，适合一般 UI / 常规字体显示
- `off`：更硬朗，适合某些像素风或你明确不想要边缘柔化的场景

## 5. 设置 Charset（字符集）

这一步很重要。

`Charset` 决定了：**最终导出的字体资源里，实际包含哪些字符。**

也就是说，如果某个字符没有进入 charset，那么最终生成资源里通常就不会有它。

你可以：

- 直接在文本框里手动填写字符
- 或者导入 `.txt` 文本文件，让系统扫描其中出现的字符并追加进去

这对于中文、符号集或项目特定文案尤其重要。

一个很实用的思路是：

- 先准备一份包含常用文本的 `.txt`
- 导入后让系统自动扫描字符
- 再手动补充少量特殊符号

## 6. 预览字体效果

Create Font 提供预览输入框与预览缩放设置。

你可以：

- 输入一段测试文字
- 调整预览缩放
- 观察当前字号、hinting、antialias 下的大致显示效果

这一步适合用来确认：

- 字体大小是否合适
- 边缘风格是否符合预期
- 中英文、数字、符号混排是否能接受

## 7. 点击 Create 生成字体资源

确认设置无误后，点击：

- **Create**

系统会根据当前字体文件、字号、字符集和渲染参数生成字体资源。

## 生成结果是什么

当前生成的字体资源不是单个文件，而是一组配套文件。

至少可以这样理解：

- 会生成一个或多个字体页图像文件
  - 例如：`_fontpageN.png`
- 还会生成一个字体元信息文件
  - 例如：`.font.txt`

也就是说，字体的图像页和它的元信息描述文件是配套存在的。

## 使用时的注意事项

和 sprite 类似，字体资源也不要只单独移动其中一部分文件。

更安全的做法是：

- 把同一套字体资源文件一起保留
- 一起移动
- 一起复制

否则可能出现：

- 只有图像页，没有元信息
- 只有元信息，没有图像页
- 资源引用不完整，导致字体加载异常

## 一个实用建议

如果你是第一次使用 Create Font，推荐顺序通常是：

1. 先选一个明确可访问的字体文件
2. 先用较小字符集做测试
3. 调整字号、hinting、antialias 看预览效果
4. 先生成一次最小可用版本
5. 确认流程正常后，再补更完整的字符集

这样会比一开始就导出超大字符集更容易排查问题。
