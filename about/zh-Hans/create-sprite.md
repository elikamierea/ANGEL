# Create Sprite

> 本页说明如何从图像帧创建 Sprite 资源。

## Create Sprite 是做什么的

`Create Sprite` 用来把一张或多张图像整理成可在项目中使用的 sprite 资源。

它比较适合这些情况：

- 你已经有一张静态图，想把它作为一个 sprite 使用
- 你有多张连续帧图，想把它们组合成一组动画帧
- 你希望明确设置 pivot，并把它一起写进资源元信息

## 基本操作流程

### 1. 打开 Create Sprite

从顶部菜单进入：

- **Resource → Create Sprite**

打开后，会看到用于导入图片、设置输出路径、命名、调整 pivot 和预览帧的界面。

### 2. 选择输入图像

在文件选择区域导入一张或多张图片。

- 只选一张时，可以把它理解成单帧 sprite
- 选多张时，这些图片会按当前导入顺序作为多个 frame 参与生成

如果你要做简单帧动画，通常就是在这里一次选入多张连续帧图。

### 3. 设置输出路径和名称

接下来需要填写：

- **Path**：输出目录
- **Name**：资源名称

默认路径通常会落在：

- `src/assets/sprites`

这也是最自然的 sprite 资源存放位置。

## 4. 调整 Pivot

Create Sprite 支持设置：

- `Pivot X`
- `Pivot Y`

Pivot 会写进生成资源的元信息里，用来描述这个 sprite 的参考点位置。

常见理解方式可以是：

- 角色脚底点
- 物体中心点
- 武器握把位置附近
- UI 图块的对齐基准点

你可以：

- 直接输入数值
- 结合预览去微调

## 5. 预览 Frame

在预览区域里，可以：

- 查看当前 frame
- 切换上一帧 / 下一帧
- 观察 pivot 位置是否合适

如果你导入了多张图，这一步尤其重要，因为它可以帮助你确认：

- 帧顺序是否符合预期
- 各帧内容是否正常
- 当前 pivot 是否适合整组帧共同使用

## 6. 点击 Create 生成资源

确认无误后，点击：

- **Create**

系统会根据当前输入图像、名称、路径和 pivot，生成对应的 sprite 资源文件。

## 生成结果是什么

这里有一个很重要的点：

**生成出来的 sprite 不是单个文件，而是两个文件。**

通常可以理解为：

1. **一个图像文件**
   - 用来存放实际的 sprite 图像内容（atlas / 合成后的图像）

2. **一个 meta 文件**
   - 用来存放这个 sprite 的描述信息
   - 例如：
     - 图像大小
     - frame 数量
     - 每帧信息
     - pivot 位置

在当前实现里，这部分元信息会作为**单独的配套文件**一起写出。

## 一个非常重要的注意事项

如果你之后要移动、复制、整理这个 sprite 资源：

- **图像文件和 meta 文件必须一起移动**
- 不要只移动其中一个

否则常见结果会是：

- 只剩图像，但项目不知道 frame / pivot 等信息
- 只剩 meta，但找不到实际图像
- 资源引用异常或加载失败

所以最安全的理解方式是：

**这两个文件共同组成一个完整的 sprite 资源。**

## 适合什么时候用

Create Sprite 比较适合：

- 快速导入角色帧动画
- 生成简单对象 sprite
- 给项目补充可直接使用的图像资源
- 在不手写资源元信息的情况下完成 sprite 生成

## 一个实用建议

如果你是第一次使用 Create Sprite，推荐顺序通常是：

1. 先用 1 张或少量几张图片测试
2. 先确认路径、名称和 pivot 是否符合预期
3. 生成后确认两个输出文件都在
4. 之后再批量处理更正式的资源

这样可以先把流程跑通，再避免后面一次性导入很多帧时排查困难。
