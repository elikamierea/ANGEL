# 节点与边编辑（基础操作全列表）

> 本页作为图编辑（Graph）部分的主入口文档，也合并了 LOD、Auto Layout、框选/拖拽/批量变换等相关说明。

## 在开始操作前：你面对的是一套什么样的系统

ANGEL GUI 里的 Graph，不只是一个“随手画框和连线”的白板。

它更像是一套**长期保存设计信息**的结构化系统，用来把项目里的想法、关系、实现方向和外部资源引用逐步沉淀下来。

你可以把它大致理解成下面几层：

### 1. 节点（Node）

节点主要用来记录一个设计单元或信息单元。

例如它可以代表：

- 一个玩法想法
- 一个系统模块
- 一个角色/对象
- 一个任务步骤
- 一个待实现的功能块

节点本身可以承载文字信息，例如：

- `name`
- `synopsis`
- `detail`
- `status`

所以节点不是单纯的图形块，而是项目设计信息的承载体。

### 2. 边（Edge）

边主要用来表达节点与节点之间的关系。

例如它可以表示：

- 依赖关系
- 调用关系
- 流程顺序
- 概念关联
- 信息来源或影响路径

因此边不是装饰线，而是 Graph 里“关系语义”的主要载体。

### 3. `resourceBindings`

Graph 还支持通过 `resourceBindings` 把节点和外部文件建立关联。

你可以把它理解成：

- 这个节点对应哪段代码
- 这个设计项关联哪个资源文件
- 这个概念最终落在哪个外部实现位置

这能让图里的设计信息，不只是停留在图上，而是逐步和项目外部文件建立对应关系。

### 4. 为什么要这样做

这套系统的目标，不只是方便你“现在看懂”，而是为了：

- 长期保存设计信息
- 让复杂项目中的关系结构可视化
- 让后续自己回看时还有上下文
- 让 agent 更容易理解项目当前设计状态并继续协作

所以从使用角度看，Graph 更像是：

- **设计信息存储层**
- **关系表达层**
- **与 agent 交流和延续上下文的中间层**

## 一、视角与导航

- **鼠标中键拖拽（MMB）** 或 **鼠标右键拖拽（RMB）**：平移视角（Pan）
- **滚轮**：以鼠标位置为中心缩放
- **Reset View 按钮**：回到默认视角

## 二、选择相关

### 1) 点选

- **左键单击节点**：单选节点
- **左键单击边/边端点**：选中边
- **Ctrl + 左键单击节点**：将节点加入或移出当前多选（toggle）
- **点击空白处**：清空选择

### 2) 框选

- **Shift + 左键拖拽**：框选（替换当前选择）
- **Ctrl + 左键拖拽**：加法框选（命中节点做 toggle）
- **Ctrl + Shift + 左键拖拽**：当前行为等同加法框选（按 Ctrl 路径处理）

注意：框选逻辑已经支持包含 **LOD hidden** 节点，避免在大图批量操作时漏选那些当前缩放下没显示出来的节点。

## 三、节点与边创建

- **N + 左键拖拽**：创建节点（拖拽决定初始尺寸）
- **N + 左键点击**：创建默认尺寸节点（以点击点为中心）
- **C + 左键拖拽（从节点起手）**：创建边
- **M + 左键拖拽（从节点起手）**：创建 mirror 节点

## 四、编辑与变换

- **拖拽节点**：移动节点（支持多选根节点一起移动）
- **拖拽节点边/角手柄**：缩放节点（Resize）
- **右键（在已多选且命中选区节点时）**：打开批量变换菜单
  - Stretch
  - Rotate 90
  - Flip Horizontal
  - Layout（选择集内预览布局）
- **变换预览会话**：
  - `Enter` 应用
  - `Esc` 取消

如果项目图已经比较大，优先学会框选和批量变换，效率会明显高很多。

## 五、LOD（缩放细节）与可见性

系统会按节点在屏幕上的面积决定显示细节。

可以简单理解为：

- 太小时可能进入 `hidden`
- 再大一些时只显示简化信息
- 继续放大后才逐步显示名字、更多细节

它的目的不是“藏东西”，而是为了让大图在缩小时仍然可读，不至于所有文字同时糊成一团。

所以当你在不同缩放下看到节点显示层级不同，这通常是正常行为。

## 六、Auto Layout（ELK）

Auto Layout 使用 ELK 来自动整理节点布局。

它适合：

- 图已经越来越复杂，手工摆放开始费劲
- 你想快速把关系图整理成更规整的结构
- 想先得到一个可读的初始布局，再手工微调

一般建议：

- 先在局部选择集上试跑
- 确认效果可接受后，再考虑更大范围使用

因为自动布局通常适合“先整理结构”，但不一定永远等于你想要的最终视觉摆法。

## 七、键盘快捷键（并入）

- `Ctrl+Z` / `Ctrl+Y`：Undo / Redo
- `Ctrl+Shift+Z`：Redo（同义路径）
- `Ctrl+S`：保存
- `Ctrl+N`：新建项目
- `Ctrl+1..4`：切换 Layer（L0..L3）
- `Ctrl+A`：全选节点
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V`：复制 / 剪切 / 粘贴预览
- 释放 `V`（在粘贴预览状态）：确认粘贴
- `Delete` 或 `D`：删除当前选中节点/边

## 八、Inspector 常用项

### 节点常用字段

- `name`
- `synopsis`
- `detail`
- `status`
- `color index`

### 边常用字段

- `relation`
- `label`
- `description`
- `path style`
- `stroke style`
- `arrow`

### 资源绑定

- 在右侧面板添加/移除 `resourceBindings`

这一步很重要，因为它决定了图里的设计项是否真正和外部文件建立了可追踪关系。
