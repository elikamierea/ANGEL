# 项目创建与打开（Project I/O）

## New Project

创建新项目时，需要选择一个起始模板。模板的区别在于搭建多少**规模**（结构与 agent）。

### Default

`Default` 是最小的起点——2 层结构，只配一个编码 agent。它更适合这类流程：

- 已经有了基本设计
- 不打算先铺很多前置结构
- 想直接开始写游戏层代码
- 更关心先把一个最小可运行闭环做起来

换句话说，`Default` 更偏向“**有设计，然后直接开始动代码**”的工作方式。

它也很适合第一次验证本地环境，因为路径更短、干扰更少。

### Extended

`Extended` 是更大的起点——4 层结构，配有设计、编排和编码 agent。它更适合这类流程：

- 已经有了一个初步设计
- 接下来还想继续完善设计
- 希望先对代码结构与实现步骤做一些规划
- 最后再逐步进入实际编码

换句话说，`Extended` 更偏向“**先整理设计与结构，再进入实现**”的工作方式。

## 项目文件夹大概长什么样

新项目创建后，本质上会生成一个工程目录。你可以大致这样理解它的结构：

### 1. 图相关信息

图编辑器中的节点、边、层级、UI 状态等项目数据，会保存在项目配置文件中。

当前项目是按“**项目目录 + 项目配置文件**”来组织的，打开项目时也是直接选择项目目录，再由 GUI 去识别里面的项目配置。

你可以把这部分理解成：

- 图结构数据
- 编辑器状态数据
- 与当前项目相关的 GUI 保存信息

### 2. 代码相关部分

代码工程主体会放在标准工程目录中，核心通常包括：

- `src/game/`：游戏层代码，最主要的实际实现区域
- `src/engine/`：底层引擎部分
- `src/platform/`：平台层
- `vendor/`：第三方依赖或随模板分发的库文件
- `tools/`：一些随项目附带的工具脚本或内置工具

如果你只是日常继续做功能，通常最常接触的是：

- `src/game/`

### 3. 资源文件放在哪里

项目资源目前主要放在：

- `src/assets/sprites/`
- `src/assets/fonts/`
- `src/assets/audio/`
- `src/assets/other/`

所以可以简单理解为：

- Sprite 资源放在 `sprites`
- 字体资源放在 `fonts`
- 音频资源放在 `audio`
- 其他杂项资源放在 `other`

这也是为什么在资源相关工具（比如 Create Sprite / Create Font）里，最终通常还是会落回这些目录。

### 4. Agent 相关信息

如果项目启用了 Agent 侧的项目内记忆/上下文文件，它们通常会按 agent 维度组织在单独目录里。

你可以把这部分理解成：

- 不同 agent 各自的记忆文件
- 一些用于会话初始化的上下文材料

这部分不是普通游戏资源，也不是底层引擎代码，而更像是“这个项目给 agent 使用的辅助信息层”。

## Open / Save / Save As

### Open

- **Open**：打开已有项目
- 当前工作流是直接选择项目目录，而不是只选某一个零散文件

### Save

- **Save**：保存当前项目状态
- 这里通常包括图编辑器里的项目数据，以及和当前项目绑定的相关保存内容

### Save As

- **Save As**：将当前项目另存到其他位置

## 一个实用理解

如果只想快速理解 New Project / Open / Save，可以先这样记：

- `Default`：更适合“有设计，直接开始写代码”
- `Extended`：更适合“先设计/完善/规划，再实现”
- 图数据保存在项目配置中
- 代码主要在 `src/`
- 资源主要在 `src/assets/`
- Agent 相关上下文信息会和项目一起组织，但属于单独的信息层
