# Theme 设置

Theme 用来调整 GUI 的整体视觉风格。你可以先选择一个 preset，再按需要继续微调。

## 可以调整什么

### 1. 基础界面颜色

包括整套主界面的常用配色，例如：

- 背景色
- 主文字颜色
- Topbar / Toolbar 颜色
- 边框颜色
- Sidebar / Right Panel 颜色
- 输入框、按钮、菜单、弹窗等界面颜色

这些设置决定了整个编辑器的基础视觉风格。

### 2. Graph 相关颜色

可以调整图编辑区域里的一些关键颜色，例如：

- 边的颜色
- 选中边颜色
- 节点文字颜色
- 节点选中态颜色
- handle / drag preview / selection preview 颜色

这些设置会影响画布中的可读性和操作反馈。

### 3. Agent Chat 与 Help 等细节颜色

除了主界面和 Graph，还可以调整一些更细的局部样式，例如：

- Agent Chat 标题栏、按钮、输入框颜色
- 不同消息气泡的背景 / 边框颜色
- 预览区颜色
- 弹窗说明文字颜色
- Help 中超链接颜色

这部分主要决定局部模块的观感是否统一。

## 除了颜色之外，还能调整什么

### 1. Preset

Theme 支持先选择一个 preset 作为起点。

这适合：

- 快速切换整体风格
- 先选一个接近的主题，再局部修改
- 在不同项目或不同偏好之间切换

### 2. Node Palette

可以调整节点配色方案（palette）。

这会影响：

- 节点填充色组
- 节点描边色组
- 节点在图中的整体配色层次

如果你希望不同节点颜色更柔和、更鲜明，或者更适合当前主题，可以从这里下手。

### 3. Grid / Node Base Opacity

可以调整一些显示透明度相关参数，例如：

- Grid 透明度
- 节点基础透明度

这会影响画布背景的存在感，以及节点整体的视觉厚重程度。

### 4. 背景图片

Theme 也支持背景图相关设置，包括：

- 是否启用背景图
- 选择背景图文件
- 清除背景图
- 调整背景图透明度

适合在不影响主工作流的前提下，给界面增加一点个性化风格。

## 推荐使用方式

比较实用的流程通常是：

1. 先选择一个最接近的 preset
2. 再调整基础界面颜色
3. 视需要微调 Graph / Agent Chat / Help 等局部颜色
4. 最后再决定是否使用背景图与透明度细调

这样会比从零开始配一整套颜色更轻松，也更不容易把整体风格调乱。
