# Create Font

> 本頁說明如何從字型檔案建立點陣字型資源。

## Create Font 是做什麼的

`Create Font` 用來把一個字型檔案轉換成專案可用的點陣字型資源。

它比較適合這些情況：

- 你想把一套字型打包進專案資源
- 你需要明確控制字級、字元集、hinting 和 antialias
- 你希望先預覽，再生成最終字型資源

## 基本操作流程

### 1. 開啟 Create Font

從頂部選單進入：

- **Resource → Create Font**

開啟後，會看到字型檔案選擇、輸出路徑、名稱、字級、字元集、預覽與匯出等相關設定。

## 2. 選擇字型檔案

先選擇一個字型檔案作為輸入。

目前支援的輸入類型包括：

- `.ttf`
- `.otf`
- `.woff`
- `.woff2`

### Windows 系統下關於「系統字型」的一個目前注意事項

如果你想在 **Windows** 下使用系統字型，目前不要直接把「系統已安裝字型」當成已經可被 GUI 直接呼叫。

**我們目前還沒有做「直接呼叫系統字型」的完整支援。**

目前可行的暫時繞過方法是：

1. 進入：`C:\Windows\Fonts`
2. 找到你要使用的字型
3. 將字型檔案複製到外部某個你方便存取的位置
4. 再在 `Create Font` 中選擇這個複製出來的字型檔案

也就是說，目前更穩妥的理解是：

- 可以使用 Windows 系統字型
- **但要先把對應字型檔案從 `C:\Windows\Fonts` 複製出來再選**

這是目前階段的暫時工作方法。

## 3. 設定輸出路徑和名稱

接下來需要填寫：

- **Path**：輸出目錄
- **Name**：資源名稱

預設路徑通常會落在：

- `src/assets/fonts`

這也是最自然的字型資源存放位置。

## 4. 設定字級、Hinting 和 Antialias

Create Font 支援設定：

- **Size**：字級
- **Hinting**：字型微調強度
- **Antialias**：是否開啟反鋸齒

### Size

字級會直接影響最終生成字型圖集的字形大小。

### Hinting

目前可選：

- `none`
- `slight`
- `normal`
- `full`

一般可以把它理解成：

- 越強的 hinting，越偏向對小字級顯示進行幾何修正
- 但具體觀感仍然需要結合字型本身和目標風格去看

### Antialias

目前可選：

- `on`
- `off`

通常可以簡單理解為：

- `on`：更平滑，適合一般 UI / 常規字型顯示
- `off`：更銳利，適合某些像素風或你明確不想要邊緣柔化的場景

## 5. 設定 Charset（字元集）

這一步很重要。

`Charset` 決定了：**最終匯出的字型資源裡，實際包含哪些字元。**

也就是說，如果某個字元沒有進入 charset，那麼最終生成資源裡通常就不會有它。

你可以：

- 直接在文字框裡手動填寫字元
- 或者匯入 `.txt` 文字檔案，讓系統掃描其中出現的字元並追加進去

這對於中文、符號集或專案特定文案尤其重要。

一個很實用的思路是：

- 先準備一份包含常用文字的 `.txt`
- 匯入後讓系統自動掃描字元
- 再手動補充少量特殊符號

## 6. 預覽字型效果

Create Font 提供預覽輸入框與預覽縮放設定。

你可以：

- 輸入一段測試文字
- 調整預覽縮放
- 觀察目前字級、hinting、antialias 下的大致顯示效果

這一步適合用來確認：

- 字型大小是否合適
- 邊緣風格是否符合預期
- 中英文、數字、符號混排是否能接受

## 7. 點擊 Create 生成字型資源

確認設定無誤後，點擊：

- **Create**

系統會根據目前字型檔案、字級、字元集和算繪參數生成字型資源。

## 生成結果是什麼

目前生成的字型資源不是單個檔案，而是一組配套檔案。

至少可以這樣理解：

- 會生成一個或多個字型頁影像檔案
  - 例如：`_fontpageN.png`
- 還會生成一個字型中繼資料檔案
  - 例如：`.font.txt`

也就是說，字型的影像頁和它的中繼資料描述檔案是配套存在的。

## 使用時的注意事項

和 sprite 類似，字型資源也不要只單獨移動其中一部分檔案。

更安全的做法是：

- 把同一套字型資源檔案一起保留
- 一起移動
- 一起複製

否則可能出現：

- 只有影像頁，沒有中繼資料
- 只有中繼資料，沒有影像頁
- 資源參照不完整，導致字型載入異常

## 一個實用建議

如果你是第一次使用 Create Font，推薦順序通常是：

1. 先選一個明確可存取的字型檔案
2. 先用較小字元集做測試
3. 調整字級、hinting、antialias 看預覽效果
4. 先生成一次最小可用版本
5. 確認流程正常後，再補更完整的字元集

這樣會比一開始就匯出超大字元集更容易排查問題。
