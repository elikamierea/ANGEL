# Create Sprite

> 本頁說明如何從影像影格建立 Sprite 資源。

## Create Sprite 是做什麼的

`Create Sprite` 用來把一張或多張影像整理成可在專案中使用的 sprite 資源。

它比較適合這些情況：

- 你已經有一張靜態圖，想把它作為一個 sprite 使用
- 你有多張連續影格圖，想把它們組合成一組動畫影格
- 你希望明確設定 pivot，並把它一起寫進資源中繼資料

## 基本操作流程

### 1. 開啟 Create Sprite

從頂部選單進入：

- **Resource → Create Sprite**

開啟後，會看到用於匯入圖片、設定輸出路徑、命名、調整 pivot 和預覽影格的介面。

### 2. 選擇輸入影像

在檔案選擇區域匯入一張或多張圖片。

- 只選一張時，可以把它理解成單影格 sprite
- 選多張時，這些圖片會按目前匯入順序作為多個 frame 參與生成

如果你要做簡單影格動畫，通常就是在這裡一次選入多張連續影格圖。

### 3. 設定輸出路徑和名稱

接下來需要填寫：

- **Path**：輸出目錄
- **Name**：資源名稱

預設路徑通常會落在：

- `src/assets/sprites`

這也是最自然的 sprite 資源存放位置。

## 4. 調整 Pivot

Create Sprite 支援設定：

- `Pivot X`
- `Pivot Y`

Pivot 會寫進生成資源的中繼資料裡，用來描述這個 sprite 的參考點位置。

常見理解方式可以是：

- 角色腳底點
- 物體中心點
- 武器握把位置附近
- UI 圖塊的對齊基準點

你可以：

- 直接輸入數值
- 結合預覽去微調

## 5. 預覽 Frame

在預覽區域裡，可以：

- 檢視目前 frame
- 切換上一影格 / 下一影格
- 觀察 pivot 位置是否合適

如果你匯入了多張圖，這一步尤其重要，因為它可以幫助你確認：

- 影格順序是否符合預期
- 各影格內容是否正常
- 目前 pivot 是否適合整組影格共同使用

## 6. 點擊 Create 生成資源

確認無誤後，點擊：

- **Create**

系統會根據目前輸入影像、名稱、路徑和 pivot，生成對應的 sprite 資源檔案。

## 生成結果是什麼

這裡有一個很重要的點：

**生成出來的 sprite 不是單個檔案，而是兩個檔案。**

通常可以理解為：

1. **一個影像檔案**
   - 用來存放實際的 sprite 影像內容（atlas / 合成後的影像）

2. **一個 meta 檔案**
   - 用來存放這個 sprite 的描述資訊
   - 例如：
     - 影像大小
     - frame 數量
     - 每影格資訊
     - pivot 位置

在目前實作裡，這部分中繼資料會作為**單獨的配套檔案**一起寫出。

## 一個非常重要的注意事項

如果你之後要移動、複製、整理這個 sprite 資源：

- **影像檔案和 meta 檔案必須一起移動**
- 不要只移動其中一個

否則常見結果會是：

- 只剩影像，但專案不知道 frame / pivot 等資訊
- 只剩 meta，但找不到實際影像
- 資源參照異常或載入失敗

所以最安全的理解方式是：

**這兩個檔案共同組成一個完整的 sprite 資源。**

## 適合什麼時候用

Create Sprite 比較適合：

- 快速匯入角色影格動畫
- 生成簡單物件 sprite
- 給專案補充可直接使用的影像資源
- 在不手寫資源中繼資料的情況下完成 sprite 生成

## 一個實用建議

如果你是第一次使用 Create Sprite，推薦順序通常是：

1. 先用 1 張或少量幾張圖片測試
2. 先確認路徑、名稱和 pivot 是否符合預期
3. 生成後確認兩個輸出檔案都在
4. 之後再批次處理更正式的資源

這樣可以先把流程跑通，再避免後面一次性匯入很多影格時排查困難。
