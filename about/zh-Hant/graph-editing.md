# 節點與邊編輯（基礎操作全列表）

> 本頁作為圖編輯（Graph）部分的主入口文件，也合併了 LOD、Auto Layout、框選/拖曳/批次變換等相關說明。

## 在開始操作前：你面對的是一套什麼樣的系統

ANGEL GUI 裡的 Graph，不只是一個「隨手畫框和連線」的白板。

它更像是一套**長期保存設計資訊**的結構化系統，用來把專案裡的想法、關係、實作方向和外部資源引用逐步沉澱下來。

你可以把它大致理解成下面幾層：

### 1. 節點（Node）

節點主要用來記錄一個設計單元或資訊單元。

例如它可以代表：

- 一個玩法想法
- 一個系統模組
- 一個角色/物件
- 一個任務步驟
- 一個待實作的功能塊

節點本身可以承載文字資訊，例如：

- `name`
- `progress`
- `detail`
- `status`

所以節點不是單純的圖形塊，而是專案設計資訊的承載體。

### 2. 邊（Edge）

邊主要用來表達節點與節點之間的關係。

例如它可以表示：

- 相依關係
- 呼叫關係
- 流程順序
- 概念關聯
- 資訊來源或影響路徑

因此邊不是裝飾線，而是 Graph 裡「關係語意」的主要載體。

### 3. `resourceBindings`

Graph 還支援透過 `resourceBindings` 把節點和外部檔案建立關聯。

你可以把它理解成：

- 這個節點對應哪段程式碼
- 這個設計項關聯哪個資源檔案
- 這個概念最終落在哪個外部實作位置

這能讓圖裡的設計資訊，不只是停留在圖上，而是逐步和專案外部檔案建立對應關係。

### 4. 為什麼要這樣做

這套系統的目標，不只是方便你「現在看懂」，而是為了：

- 長期保存設計資訊
- 讓複雜專案中的關係結構視覺化
- 讓後續自己回看時還有上下文
- 讓 agent 更容易理解專案目前設計狀態並繼續協作

所以從使用角度看，Graph 更像是：

- **設計資訊儲存層**
- **關係表達層**
- **與 agent 交流和延續上下文的中間層**

## 一、視角與導覽

- **滑鼠中鍵拖曳（MMB）** 或 **滑鼠右鍵拖曳（RMB）**：平移視角（Pan）
- **滾輪**：以滑鼠位置為中心縮放
- **Reset View 按鈕**：回到預設視角

## 二、選擇相關

### 1) 點選

- **左鍵單擊節點**：單選節點
- **左鍵單擊邊/邊端點**：選取邊
- **Ctrl + 左鍵單擊節點**：將節點加入或移出目前多選（toggle）
- **點擊空白處**：清空選擇

### 2) 框選

- **Shift + 左鍵拖曳**：框選（取代目前選擇）
- **Ctrl + 左鍵拖曳**：加法框選（命中節點做 toggle）
- **Ctrl + Shift + 左鍵拖曳**：目前行為等同加法框選（按 Ctrl 路徑處理）

注意：框選邏輯已經支援包含 **LOD hidden** 節點，避免在大圖批次操作時漏選那些目前縮放下沒顯示出來的節點。

## 三、節點與邊建立

- **N + 左鍵拖曳**：建立節點（拖曳決定初始尺寸）
- **N + 左鍵點擊**：建立預設尺寸節點（以點擊點為中心）
- **C + 左鍵拖曳（從節點起手）**：建立邊
- **M + 左鍵拖曳（從節點起手）**：建立 mirror 節點

## 四、編輯與變換

- **拖曳節點**：移動節點（支援多選根節點一起移動）
- **拖曳節點邊/角控制點**：縮放節點（Resize）
- **右鍵（在已多選且命中選區節點時）**：開啟批次變換選單
  - Stretch
  - Rotate 90
  - Flip Horizontal
  - Layout（選擇集內預覽配置）
- **變換預覽工作階段**：
  - `Enter` 套用
  - `Esc` 取消

如果專案圖已經比較大，優先學會框選和批次變換，效率會明顯高很多。

## 五、LOD（縮放細節）與可見性

系統會按節點在螢幕上的面積決定顯示細節。

可以簡單理解為：

- 太小時可能進入 `hidden`
- 再大一些時只顯示簡化資訊
- 繼續放大後才逐步顯示名字、更多細節

它的目的不是「藏東西」，而是為了讓大圖在縮小時仍然可讀，不至於所有文字同時糊成一團。

所以當你在不同縮放下看到節點顯示層級不同，這通常是正常行為。

## 六、Auto Layout（ELK）

Auto Layout 使用 ELK 來自動整理節點配置。

它適合：

- 圖已經越來越複雜，手動擺放開始費勁
- 你想快速把關係圖整理成更規整的結構
- 想先得到一個可讀的初始配置，再手動微調

一般建議：

- 先在局部選擇集上試跑
- 確認效果可接受後，再考慮更大範圍使用

因為自動配置通常適合「先整理結構」，但不一定永遠等於你想要的最終視覺擺法。

## 七、鍵盤快捷鍵（併入）

- `Ctrl+Z` / `Ctrl+Y`：Undo / Redo
- `Ctrl+Shift+Z`：Redo（同義路徑）
- `Ctrl+S`：儲存
- `Ctrl+N`：新建專案
- `Ctrl+1..4`：切換 Layer（L0..L3）
- `Ctrl+A`：全選節點
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V`：複製 / 剪下 / 貼上預覽
- 釋放 `V`（在貼上預覽狀態）：確認貼上
- `Delete` 或 `D`：刪除目前選取節點/邊

## 八、Inspector 常用項

### 節點常用欄位

- `name`
- `progress`
- `detail`
- `status`
- `color index`

### 邊常用欄位

- `relation`
- `label`
- `description`
- `path style`
- `stroke style`
- `arrow`

### 資源引用

- 在右側面板新增/移除 `resourceBindings`

這一步很重要，因為它決定了圖裡的設計項是否真正和外部檔案建立了可追蹤關係。
