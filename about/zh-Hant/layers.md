# Layer 系統

Layer 用來表達資訊展開層次。

它不是單純的「顯示開關」，而更像是在同一套圖結構上控制：

- 目前看到多少細節
- 目前編輯針對的是哪一層資訊
- 某些設計內容應該在哪個抽象層級上表達

## Layer 大致是怎麼運作的

常見的理解方式是：

- 越低層，越偏向更概括、更骨架的資訊
- 越高層，越偏向更展開、更具體的內容

在使用上，目前作用中的層通常會影響：

- 可見範圍
- 可編輯範圍
- 某些節點目前展示出來的 detail 層次

## 目前並不是所有專案都一定是同一套層數

這裡有一個需要特別說明的點：

**並不是所有專案都一定按完全相同的 Layer 複雜度來使用。**

目前你可以大致這樣理解：

### 1. 四層模式

有些專案會使用更完整的四層表達，也就是常見的：

- `L0`
- `L1`
- `L2`
- `L3`

這種模式更適合：

- 圖結構更複雜
- 設計展開層次更多
- 希望把資訊分得更細

### 2. 簡化模式

也有些專案會把 Layer 的使用方式簡化到兩層來理解和使用。

這種模式更適合：

- 專案本身規模較小
- 設計層次不需要拆得太細
- 更希望盡快進入直接實作，而不是維護過多抽象層

所以在實際專案裡，Layer 的「存在」是統一的，但「你要把它用到多細」可以是不同的。

## 使用建議

如果你是第一次用 Layer，最實用的理解方式通常是：

- 先把它當成「資訊展開層次」
- 不要一開始就執著於把每一層定義得非常理論化
- 根據專案複雜度決定是按四層細分，還是按更簡化的方式使用

如果你的專案比較大、設計關係很多，四層會更有幫助；如果專案目標更直接、節奏更快，簡化使用通常也完全可行。

## 快速切換

常見快捷方式：

- `Ctrl+1..4`：切換 Layer（L0..L3）
