# Theme 設定

Theme 用來調整 GUI 的整體視覺風格。你可以先選擇一個 preset，再按需要繼續微調。

## 可以調整什麼

### 1. 基礎介面顏色

包括整套主介面的常用配色，例如：

- 背景色
- 主文字顏色
- Topbar / Toolbar 顏色
- 邊框顏色
- Sidebar / Right Panel 顏色
- 輸入框、按鈕、選單、彈出視窗等介面顏色

這些設定決定了整個編輯器的基礎視覺風格。

### 2. Graph 相關顏色

可以調整圖編輯區域裡的一些關鍵顏色，例如：

- 邊的顏色
- 選取邊顏色
- 節點文字顏色
- 節點選取狀態顏色
- handle / drag preview / selection preview 顏色

這些設定會影響畫布中的可讀性和操作回饋。

### 3. Agent Chat 與 Help 等細節顏色

除了主介面和 Graph，還可以調整一些更細的局部樣式，例如：

- Agent Chat 標題列、按鈕、輸入框顏色
- 不同訊息泡泡的背景 / 邊框顏色
- 預覽區顏色
- 彈出視窗說明文字顏色
- Help 中超連結顏色

這部分主要決定局部模組的觀感是否統一。

## 除了顏色之外，還能調整什麼

### 1. Preset

Theme 支援先選擇一個 preset 作為起點。

這適合：

- 快速切換整體風格
- 先選一個接近的主題，再局部修改
- 在不同專案或不同偏好之間切換

### 2. Node Palette

可以調整節點配色方案（palette）。

這會影響：

- 節點填充色組
- 節點描邊色組
- 節點在圖中的整體配色層次

如果你希望不同節點顏色更柔和、更鮮明，或者更適合目前主題，可以從這裡下手。

### 3. Grid / Node Base Opacity

可以調整一些顯示透明度相關參數，例如：

- Grid 透明度
- 節點基礎透明度

這會影響畫布背景的存在感，以及節點整體的視覺厚重程度。

### 4. 背景圖片

Theme 也支援背景圖相關設定，包括：

- 是否啟用背景圖
- 選擇背景圖檔案
- 清除背景圖
- 調整背景圖透明度

適合在不影響主工作流的前提下，給介面增加一點個人化風格。

## 推薦使用方式

比較實用的流程通常是：

1. 先選擇一個最接近的 preset
2. 再調整基礎介面顏色
3. 視需要微調 Graph / Agent Chat / Help 等局部顏色
4. 最後再決定是否使用背景圖與透明度細調

這樣會比從零開始配一整套顏色更輕鬆，也更不容易把整體風格調亂。
