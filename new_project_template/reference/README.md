# reference/

本目录存放**供 agent 与开发者参考、但不随游戏成品发布**的资料。这里的任何内容都不会被编译进游戏，也不应打包进你分发给玩家的最终产物。

## 当前内容

- `engine/` — ANGEL 引擎的权威文档：`README.md`（总览/快速上手）、`MANUAL.md`（手册索引）与各 `MANUAL_*.md`（分模块手册）。写游戏代码前先查这里。

## 预留分类

后续「不进成品、仅供参考」的东西可作为 `engine/` 的兄弟目录放进来，例如：

- `design/` — 策划案、设计稿、参考图
- `notes/` — agent 的踩坑笔记与调查结论
- `asset_sources/` — 未打包的原始素材（工程文件、母带等）

需要新增分类时，直接建子目录即可，无需改动构建流程。
