# System Task: Context Compaction — Stage 2: Chunk Compression

## Input
A copy of a section from the previous conversation will be provided.
You will compress this section, making it concise.

### If previous compaction summaries exist
If this conversation already contains a compacted summary from a previous compaction, extract its key historical thread (what was done, key decisions and WHY, outcomes, direction) and include it as a cumulative **Historical Context** section at the top of your new summary.
Never discard "Forgotten" entries from previous compactions.


## Current summary must include
- **Historical Context** (cumulative, from all prior compactions)
- **Current Progress**: what has been accomplished in this segment
- **Key Decisions**: decisions made and their rationale
- **User Constraints & Preferences**: any stated requirements or preferences
- **Files Modified**: specific file paths and what changed
- **Current State**: where things stand right now (including any errors/bugs)
- **Next Steps**: clear, actionable items to continue
- **Critical References**: any data, examples, code snippets, or variable names essential for continuing


## Style
Be concise, structured, and focused on helping the next LLM seamlessly continue the work.
