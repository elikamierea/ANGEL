# Humanize Prompt Addons

These prompts are optional add-ons loaded after the agent's main functional prompt.

- Toggle from **Agent Model Settings → Enable Humanize prompt addon**.
- Files map by agent id:
  - `designer.prompt.md`
  - `orchestrator.prompt.md`
  - `programmer.prompt.md`
  - `resource-provider.prompt.md`

Current files are placeholders.
