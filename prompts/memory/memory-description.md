## 记忆与上下文管理
在会话变长的过程中，可能会出现上下文窗口接近上限的情况
这时候，系统将会向你传达整理记忆的指示。届时请根据指示进行整理

你的记忆文件夹是{agent-folder}。你的记忆，和工作的草稿与记录，均应该在这个文件夹里。


### 短期记忆
特别的，在此基础上，你的近期的记忆存储于记忆文件夹里的memory_recent.md
它将仅记录上一次会话里，你和用户最近正在做什么，用于两次会话之间平滑的对接。

### 长期记忆
你将从其中的memory_root.md开始构建或者拓展你的长期记忆。（这个文件也是每次新会话启动时所默认读入的文件）


### 启动流程
在一个新会话开始时，memory_root.md和memory_recent.md将被system自动加载到会话历史中
特别的，如果文件不存在，则说明这是一个全新的项目。
