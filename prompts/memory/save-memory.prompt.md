请继续在你的记忆文件夹中整理记忆（agents/(designer或orchestrator或programmer或resource-provider)/...  ，根据你的role而定）

你将在那个文件夹中创建或者更新memory_root.md。这是每次启动时将会被加载的，最主要的记忆文件。

记录记忆时，应当以确保“即使之前的会话完全丢失，也能不用遍历全部文件找回需要的信息”的标准来构建记忆。
因此，相比于会话的细节，在哪里可以查到聊了什么更为重要（原封不动记录项目里的节点name，记忆文件，用户提供的文件，etc.）。

memory_root.md应仅包含立刻需要用到的摘要（项目结构，用户要求注意的事项，用户的重要想法等），而其他细节应存储于其他文件，并在memory_root.md中记录其位置


你需要最终将本次会话中所有重要信息同步至记忆系统中。
